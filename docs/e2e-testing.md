# Manual E2E Checklist

Status: Active
Last reviewed: 2026-06-20

Use this checklist before a public build or after broad UI/runtime changes.
Manual runs may use real API keys, but never record keys, local paths, or
private filenames in tracked files.

## Startup

- Launch `python app.py --dev`.
- Launch `python app.py --browser`.
- Launch `python app.py --prod` after `cd frontend && npm run build`.
- Confirm the left rail shows Model, Translation, Glossary Extraction, Glossary
  Review, General Tools, and App Settings.
- Confirm a cold cache creates default settings and prompt preset files.
- Confirm a warm cache restores settings, active model, and active prompt.

## App Settings

- Switch interface language between Chinese and English.
- Change UI scale and verify layout remains usable.
- Set and clear proxy URL.
- Run update check and verify network errors are shown clearly.

## Model Library

- Create a profile from a provider template.
- On a clean cache, complete or skip the first-use model onboarding.
- Edit a saved profile and verify API keys display in edit mode.
- Test connection with a saved profile.
- Test connection with unsaved inline credentials.
- Fetch model list for a provider that supports it.
- Select active model for Translation, Glossary Extraction, and Glossary Review
  separately.
- Delete an active profile and verify the matching active id clears.

## Prompt Presets

- Verify only the system preset matching the current UI language is shown.
- View a system preset and confirm it is read-only.
- Duplicate a system preset and edit the custom copy.
- Delete an active custom preset and confirm fallback behavior.
- Verify the modal does not expose thinking guidance.

## Translation

- Configure input/output folders and languages.
- Add glossary entries manually.
- Add conflicting glossary entries and verify non-blocking warnings appear.
- Import glossary XLSX/JSON generated by Glossary Extraction.
- Add text-preserve rules.
- Add pre/post replacement rules.
- Start a TXT translation with a small fixture.
- Stop and continue a task.
- Restart the app and confirm continuable cache recovery.
- Verify output filenames use `<OriginalName>-<targetTag>.<ext>`.
- Verify bilingual output when enabled.
- Verify failed subtasks show message, attempts, and timestamp.
- Open the request-log pop-out during a run, expand a row, and verify request
  status, timing, token fields, model response, and retained failure records
  are visible when present.
- Verify elapsed time reflects active runtime rather than the task creation
  time.

## Glossary Extraction

- Configure input/output folders and languages.
- Toggle combined folder glossary.
- Toggle identical source/destination retention.
- Toggle width normalization.
- Run extraction on a small fixture.
- Verify per-source XLSX/JSON/references TXT outputs.
- Verify combined output when enabled.
- Verify decode issue artifact appears when decoding issues occur.
- After completion, click Send to Review and verify the review Settings page
  receives the extraction output folder and novel background.
- Open the request-log pop-out during extraction.
- Stop, continue, and restart-recover a task.

## Glossary Review

- Configure input folder and output filename.
- Confirm XLSX and TXT candidates are discovered from the input folder.
- Select one glossary XLSX and one or more reference TXT files.
- Fill novel background and review rounds.
- Run review and confirm round-aware progress.
- Open the request-log pop-out during review.
- Verify final XLSX and changed-row report artifacts.
- Open the report and restore a deleted row.
- Open the final table review page, sort rows, edit a row, multi-select rows,
  and bulk-delete selected rows.
- Import the final XLSX into the Translation glossary as replace.
- Import again and verify exact duplicate rows are skipped.
- Stop, continue, and restart-recover a task.

## Batch Replacement

- Import TXT rules in `src->dst` form.
- Import TXT rules in `src#->#dst` and `src# -> #dst` forms.
- Confirm delimiter-adjacent `#` markers are removed from parsed rules.
- Confirm unrelated `#` characters remain.
- Edit imported rule source/destination in the table.
- Toggle regex and case sensitivity.
- Run TXT replacement and verify output content/count.
- Run EPUB replacement and verify structure is preserved.
- Stop an active replacement run.
- Verify artifacts and replacement report are visible after completion.

## EPUB Tools

- Open General Tools and confirm EPUB Tools shows EPUB Compressor, Document
  Merger, EPUB to TXT, TXT to EPUB, EPUB Metadata, and EPUB Repair.
- Run EPUB Compressor on one EPUB and verify the output opens as a valid EPUB,
  preserves title metadata, and exposes a compression report.
- Run Document Merger on at least two EPUB files, reorder the inputs, and verify
  the merged EPUB has regenerated navigation and readable chapters.
- Run Document Merger on TXT inputs when available and verify output order
  matches the UI order.
- Run EPUB to TXT on one EPUB and verify the TXT output is UTF-8 text with a
  conversion report.
- Run TXT to EPUB with the Markdown preset and verify numeric body lines are not
  promoted to headings unless explicitly marked.
- Run TXT to EPUB with a numeric/chapter preset and verify detected headings can
  be located from the preview.
- Read EPUB Metadata, change title/author or cover, apply to a copy, and verify
  the edited EPUB opens with the new metadata.
- Run EPUB Repair on a malformed fixture and verify repaired output plus repair
  counts/validation details are shown.
- Stop an active single-pass EPUB/TXT tool task and verify the UI does not offer
  resumable continue for it.

## Packaging

- Build macOS app/DMG with `python build_macos.py`.
- Build Windows package on Windows with `python build_windows.py`.
- Confirm packaged macOS user data goes to
  `~/Library/Application Support/Transoria`.
- Confirm packaged Windows user data stays in `User Data` next to the EXE when
  writable, and falls back to `%LOCALAPPDATA%\Transoria` when the install
  folder is not writable.
- Confirm local `.env`, `.transoria-cache`, and API-key files are not bundled.
